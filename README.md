# kpn-opendata

観劇ポータル名古屋に関連するオープンデータを公開するリポジトリです。

## ファイル

ファイル名は `kpn-<出し手>-<中身>.json` の形式です。

| ファイル | 内容 | 出し手 |
|---|---|---|
| `kpn-calbymuse-shows.json` | 名古屋・東海地方の小劇場公演情報（本編のみ） | 観劇ポータル名古屋 by Muse |

## 更新

`kpn-calbymuse-shows.json` は週1回、日曜日に最新の内容へ更新されます。

## 注意

- 掲載情報は公開情報をもとに収集したものです。最新の公演情報は各公演の公式サイトでご確認ください。
- データ形式は予告なく変更される場合があります。
